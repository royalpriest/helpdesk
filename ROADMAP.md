# Roadmap

## v0.1: A usable shared inbox (now)
- [x] Incoming email becomes tickets (Action Mailbox)
- [x] Replies thread onto the right ticket
- [x] Assign tickets, change status, filter the inbox
- [x] Canned replies
- [x] Customer portal via private link
- [ ] Strip quoted text from email replies
- [ ] Attachments on incoming and outgoing messages
- [ ] Internal notes agents can see but customers can't
- [ ] Agent management screen (invite, deactivate)

## v0.2: Working as a team
- [ ] Live inbox updates with Turbo Streams
- [ ] Notify an agent when a ticket is assigned to them
- [ ] Search across tickets
- [ ] Tags and saved views

## v0.3: Running it for real
- [ ] Auto-close pending tickets after N days
- [ ] Customer satisfaction rating after close
- [ ] Multiple inboxes (e.g. support@ and billing@)
- [ ] Docker image and one-click deploy guides
